# PK Hosting Pricing Page

A mobile-friendly pricing page for PK Hosting with a billing-term toggle (annual/monthly), a promo code field, and one data source (a single `PLANS` object in `index.html`) that drives both the plan cards and the comparison table.

Prices verified live from https://www.pkhosting.com/pricing/ on 11 November 2026. Monthly prices follow the site's own rule: annual price x 1.2 / 12. No promo code is currently active.

Live: https://pakmultilinks-dot.github.io/pkhosting-pricing-page/
